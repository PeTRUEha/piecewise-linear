## Why

Нужен самостоятельный демонстрационный сервис для хранения и интерактивного редактирования упорядоченного набора точек на плоскости. Сервис должен сразу запускаться локально и разворачиваться на одном Linux-сервере без установки Python, Node.js или менеджеров зависимостей на сервер.

## What Changes

- Создать новый независимый full-stack-сервис `piecewise-linear`.
- Реализовать единственную страницу со списком точек слева и графиком справа.
- Загружать точки из PostgreSQL в порядке их идентификаторов.
- Позволить пользователю добавлять, редактировать, удалять и перемещать точки вверх или вниз.
- При изменении порядка сохранять в базе весь новый порядок точек, обновляя их идентификаторы.
- Обновлять список и график непосредственно по мере пользовательских изменений.
- Соединять точки на графике в порядке их идентификаторов.
- Предоставить асинхронный HTTP API и OpenAPI-документацию.
- Добавить отдельные проверки работоспособности процесса и доступности PostgreSQL.
- Обеспечить локальный запуск и production-развёртывание через Docker Compose.
- Добавить автоматизированные проверки качества, backend-тесты, интеграционные тесты с PostgreSQL и сквозные браузерные тесты.
- Авторизация в эту версию не входит.

## Capabilities

### New Capabilities

- `point-management`: загрузка, добавление, редактирование, удаление и переупорядочивание хранимых точек.
- `point-plot`: отображение упорядоченных точек на координатной плоскости и их соединение линиями с немедленным отражением пользовательских изменений.
- `service-health`: проверки активности backend-процесса и готовности PostgreSQL.
- `service-runtime`: локальный запуск и production-развёртывание полного сервиса в контейнерах.

### Modified Capabilities

Нет.

## Impact

- Новый самостоятельный репозиторий `PeTRUEha/piecewise-linear`.
- Новый React/TypeScript/Vite frontend.
- Новый асинхронный FastAPI backend с единственным импортируемым пакетом `piecewise_linear`.
- Новая схема PostgreSQL и Alembic-миграции.
- Новые HTTP API-контракты для работы с точками и проверки состояния сервиса.
- Новая Docker Compose-инфраструктура для локальной и production-среды.
- Новые настройки CI, проверок качества и тестирования.
