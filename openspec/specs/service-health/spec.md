# Проверки состояния сервиса

## Требования

### Требование: Проверка активности процесса
Система ДОЛЖНА предоставлять `GET /api/v1/health/live`, который проверяет только способность backend-процесса обслуживать запросы и не обращается к PostgreSQL.

#### Сценарий: Backend работает при недоступной базе
- **КОГДА** backend-процесс работает, но PostgreSQL недоступен
- **ТОГДА** запрос `GET /api/v1/health/live` возвращает успешный статус

### Требование: Проверка готовности
Система ДОЛЖНА предоставлять `GET /api/v1/health/ready`, который асинхронно проверяет доступность PostgreSQL.

#### Сценарий: База доступна
- **КОГДА** backend может выполнить проверочный запрос к PostgreSQL
- **ТОГДА** `GET /api/v1/health/ready` возвращает успешный статус

#### Сценарий: База недоступна
- **КОГДА** backend не может выполнить проверочный запрос к PostgreSQL
- **ТОГДА** `GET /api/v1/health/ready` возвращает неуспешный статус готовности
