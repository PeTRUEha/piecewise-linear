# Инструкции проекта

- Разработка ведётся по артефактам OpenSpec в каталоге `openspec/`.
- Документация и ADR пишутся на русском языке.
- Backend использует Python 3.13, FastAPI, Advanced Alchemy, asyncpg и Alembic.
- Frontend использует React, TypeScript, Vite, Recharts и dnd-kit.
- Перед завершением изменений выполняются соответствующие статические проверки и сборки.
- Тесты добавляются только после явного одобрения пользователем основного кода.
- Коммиты создаются только по прямому указанию пользователя.
