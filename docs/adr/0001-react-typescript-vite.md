# ADR 0001: React, TypeScript и Vite для frontend

- Статус: принято
- Дата: 2026-09-05

## Контекст

Проект содержит отдельный одностраничный frontend с интерактивным графиком и отдельный backend на FastAPI.

## Решение

Использовать React и TypeScript со сборкой Vite. FastAPI остаётся отдельным backend и предоставляет данные через API.

Для графика использовать Recharts. Для перетаскивания использовать dnd-kit.

## Причины

- React широко распространён и хорошо знаком AI-агентам.
- React подходит для интерактивных интерфейсов, графиков и дашбордов.
- Vite обеспечивает запуск, разработку и сборку frontend-приложения.
- FastAPI отвечает за данные и вычисления, React — за взаимодействие и визуализацию.

## Альтернативы

Next.js не выбран как стандартный вариант, поскольку его основные преимущества — SSR, SEO и server-side возможности — не требуются клиентскому интерфейсу поверх FastAPI. Использовать Next.js следует при явной потребности в этих возможностях.

## Последствия

- Frontend и backend развиваются отдельно.
- Маршрутизацию и другую клиентскую инфраструктуру нужно выбирать отдельно.
