# ADR 0004: Контейнерное развёртывание

- Статус: принято
- Дата: 2026-09-05

## Контекст

Приложение состоит из frontend, backend и PostgreSQL.

## Решение

Использовать Docker Compose для запуска приложения.

Собирать компоненты в многоэтапных образах. Использовать Nginx для раздачи frontend. Не публиковать порт PostgreSQL на production-сервере.
