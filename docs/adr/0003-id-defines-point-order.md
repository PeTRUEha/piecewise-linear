# ADR 0003: Идентификатор определяет порядок точек

- Статус: принято
- Дата: 2026-09-05

## Контекст

Точка содержит поля `id`, `x` и `y`. Порядок точек хранится в PostgreSQL и изменяется целиком.

## Решение

Определять порядок точек по возрастанию `id`.

При изменении порядка удалить и записать заново весь набор точек в одной транзакции, назначив им последовательные идентификаторы `1…N`.
