# Синхронизация спецификаций OpenSpec

Операция выполняется агентом: прочитай delta-спецификации и аккуратно внеси их смысл в основные спецификации.

## Порядок работы

1. Если названо хранилище, выполни `openspec store list --json` и используй `--store <id>`.
2. Если имя изменения не указано, выполни `openspec list --json`, покажи активные изменения с delta-спецификациями и попроси пользователя выбрать одно.
3. Выполни `openspec status --change "<имя>" --json`.
4. Возьми список delta-спецификаций из `artifactPaths.specs.existingOutputPaths`.
5. Для каждой спецификации прочитай delta-файл и соответствующий основной файл `openspec/specs/<возможность>/spec.md`.
6. Применяй изменения по смыслу:
   - добавление — внеси новое требование;
   - изменение — обнови только указанное поведение, сохранив не затронутые сценарии;
   - удаление — удали полный блок требования;
   - переименование — переименуй существующее требование.
7. Если основная спецификация отсутствует, создай её с краткой целью и перенеси добавленные требования.
8. Покажи перечень обновлённых возможностей и внесённых изменений. Изменение остаётся активным.

## Ограничения

- Перед правкой всегда читай и delta-, и основную спецификацию.
- Не удаляй неупомянутый сценарий или требование.
- Делай операцию идемпотентной.
- При неоднозначности остановись и запроси уточнение.
