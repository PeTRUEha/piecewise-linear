# Применение изменения OpenSpec

## Выбор изменения и хранилища

Если названо хранилище, найди его через `openspec store list --json` и используй `--store <id>`. Если имя изменения отсутствует, выведи `openspec list --json`: выбери единственное активное изменение автоматически, а при нескольких попроси пользователя выбрать. Объяви выбранное имя и способ переопределить выбор.

## Подготовка

1. Выполни `openspec status --change "<имя>" --json` и определи схему, расположение и артефакт с задачами.
2. Выполни `openspec instructions apply --change "<имя>" --json`.
3. Прочитай каждый файл из `contextFiles`.
4. Сообщи схему, общий прогресс и оставшиеся задачи.

## Реализация

Для каждой незавершённой задачи:

1. Объяви, над какой задачей работаешь.
2. Внеси минимальные изменения, необходимые для задачи.
3. Проверь результат в объёме, соответствующем риску.
4. Сразу отметь задачу в файле задач как выполненную: `- [ ]` → `- [x]`.

Остановись и запроси направление, если задача неясна, найдено противоречие в проектировании, возникла ошибка или требуется решение пользователя. При завершении покажи выполненные задачи и общий прогресс.

## Ограничения

- До начала всегда читай файлы из `contextFiles`.
- Не реализуй за пределами согласованных задач.
- Не помечай задачу выполненной до завершения её работы.
- Не продолжай при блокирующем противоречии или неясности.
