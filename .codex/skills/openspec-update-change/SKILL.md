# Обновление изменения OpenSpec

Этот навык меняет только уже существующие плановые артефакты и никогда не изменяет реализацию.

## Порядок работы

1. При необходимости выбери хранилище через `openspec store list --json` и `--store <id>`.
2. Если изменение не названо, выполни `openspec list --json` и предложи пользователю выбрать активное изменение.
3. Выполни `openspec status --change "<имя>" --json`.
4. Используй только конкретные пути из `artifactPaths.<идентификатор>.existingOutputPaths`; не записывай в glob-путь `resolvedOutputPath` и не создавай отсутствующие артефакты.
5. Прочитай затронутые и связанные существующие артефакты. Найди противоречия, пробелы и последствия изменения.
6. Для каждого артефакта отдельно покажи предлагаемую правку и причину. Записывай её только после явного одобрения пользователя.
7. После записи проверь согласованность остальных существующих артефактов и сообщи о том, что отложено.

## Ограничения

- Не создавай новые артефакты: для этого используется отдельный workflow продолжения изменения.
- Не переходи к коду; при необходимости реализации укажи `/opsx:apply`.
- Не меняй намерение изменения молча: если требуется другая цель, предложи новое изменение.
